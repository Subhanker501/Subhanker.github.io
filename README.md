# Subhanker Howlader — academic website

Elegant academic, mobile-responsive static website for GitHub Pages.

## Deploy on GitHub

1. Sign in to GitHub as `Subho123rr`.
2. Open your repository named `Subho123rr.github.io` or create it if necessary.
3. To replace an old homepage, upload the new `index.html` and `favicon.svg` **directly to the repository root**. GitHub allows you to commit updated versions without deleting old files first.
4. Click **Commit changes**.
5. In **Settings → Pages**, choose **Deploy from a branch**, `main`, `/(root)`, then Save.
6. Visit https://subho123rr.github.io/ after the deployment completes (check the Actions tab).

## Customize

- **Email and academic profiles:** open `index.html` in GitHub, click the pencil/edit icon, replace placeholder text in the Contact section, then commit.
- **CV:** upload your PDF to the repository root under the exact name `cv.pdf`; the existing CV button will then work. Until then it points to a missing file.
- **Portrait:** current website uses a decorative physics illustration instead of a portrait, because no photograph was provided.
- **Publications:** six publications transcribed from `List_of_publications_Subhanker.pdf`; links to DOI/publisher pages where verified, and a Scholar title search for the Physics of Fluids paper where its DOI was not verified.
- **Name/affiliation:** Ph.D. in Physics, IISER Mohali, January 2022–August 2026.
- **Photo, if desired:** you can replace the hero illustration with an `<img>` element linking to a file such as `profile.jpg`.
- **External fonts:** uses Google Fonts, with Georgia/Arial fallbacks.

Avoid deleting your GitHub account or repository. To clean up old site files such as unused CSS or image assets, delete only those files after replacing the homepage.
